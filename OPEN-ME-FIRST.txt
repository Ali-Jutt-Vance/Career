TO OPEN THE BOOK (no install, nothing to run):

  It opens on today's plan. Keys: T = today, / = search, arrows = prev/next day.

TO GET THE DESKTOP ICON (chromeless window, own profile, custom icon):
  Double-click  "Install Desktop Icon.cmd"  in this folder.
  Or open PowerShell in this folder and run:
      powershell -ExecutionPolicy Bypass -File curriculum\app\install-app.ps1
  That creates "Career Book" on your Desktop and in the Start Menu.

TO REBUILD AFTER EDITING (optional):
  cd curriculum
  npm install
  npm run build      <- regenerates the plan + reader, runs all assertions + smoke test
