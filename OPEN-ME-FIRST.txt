BECOMING A SOFTWARE ENGINEER
============================
A patient, complete course - from your very first line of code to the level of an
engineer with five years of experience. 176 chapters in 15 parts.

TO READ THE BOOK (nothing to install):
  Double-click  curriculum\output\index.html  (opens in Chrome or Edge)

  Contents are on the left. Search box at the top (press / to jump to it).
  Arrow keys move between chapters. Glossary and Index are at the bottom of the contents.
  The book reopens where you stopped.

TO GET A DESKTOP ICON (opens like an app, in its own window):
  Double-click  "Install Desktop Icon.cmd"  in this folder (needs Chrome, Edge or Brave).

TO REBUILD AFTER CHAPTERS CHANGE (optional):
  cd curriculum
  npm install        (first time only)
  npm run build      (checks the chapters, then rebuilds output\index.html)

TO CONTINUE WRITING THE BOOK:
  Read  curriculum\CONTINUE-HERE.md

WHAT IS IN HERE
  curriculum\book\chapters\     the rewritten chapters (the real book)
  curriculum\book\toc.json      the table of contents: all 176 chapters
  curriculum\book\STYLE-GUIDE.md  how every chapter is written
  curriculum\source-notes\      old condensed notes, used as raw material for unfinished chapters
  curriculum\REWRITE-STATUS.md  which chapters are finished
  curriculum\output\index.html  the built reader (this is the book you open)
  README.md                     a fuller explanation

NOT INCLUDED (created on each computer)
  curriculum\node_modules\      run: npm install
  curriculum\app\profile\       the desktop app's private browser profile
